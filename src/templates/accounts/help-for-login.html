Comment se connecter

Pour accéder aux fonctionnalités de l'application de suivi de la collecte, veuillez suivre ces étapes simples pour vous connecter :

  1. Cliquez sur le lien Se Connecter situé en haut à droite de la page d'accueil.
  2. Sur la page de connexion, saisissez votre nom d'utilisateur dans le champ "Nom d'utilisateur".
  3. Entrez votre mot de passe dans le champ "Mot de passe".
  4. Cliquez sur le bouton "Connexion" pour accéder à votre compte.

Conseils pour une connexion réussie :

  • Assurez-vous que le verrouillage des majuscules est désactivé.
  • Vérifiez que vous utilisez le bon nom d'utilisateur et le bon mot de passe.
  • Si vous avez oublié votre mot de passe, contacter l'administrateur pour le réinitialiser.

Si vous rencontrez des difficultés pour vous connecter, veuillez consulter la section problèmes de connexion ou en cas de difficulté majeure, contacter l'administrateur.

Problèmes de connexion

Si vous rencontrez des difficultés pour vous connecter à votre compte, voici quelques conseils :

  • Vérifiez votre nom d'utilisateur et votre mot de passe : Assurez-vous que vous avez saisi les informations correctes, en respectant les majuscules et les minuscules.
  • Consulter le mail que vous avez reçu indiquant votre login : Veuillez ouvrir vos mails et consulter le mail que vous avez reçu de l'administrateur @hunnakey vous indiquant vos accès à l'application
  • Vérifiez votre connexion Internet : Assurez-vous que vous avez une connexion Internet stable.
  • Effacez le cache et les cookies de votre navigateur : Parfois, les données mises en cache peuvent interférer avec la connexion. Essayez d'effacer le cache et les cookies de votre navigateur.

Problèmes techniques

Si vous rencontrez des problèmes techniques sur le site web, tels que des pages qui ne se chargent pas ou des fonctionnalités qui ne fonctionnent pas correctement, voici quelques mesures que vous pouvez prendre :

  • Actualisez la page : Parfois, un simple rechargement de la page peut résoudre le problème.
  • Essayez un autre navigateur : Si le problème persiste, essayez d'accéder au site web à partir d'un autre navigateur (par exemple, Chrome, Firefox, Safari).
  • Vérifiez les mises à jour du navigateur : Assurez-vous que votre navigateur est à jour avec la dernière version.
  • Redémarrez votre ordinateur : Le redémarrage de votre ordinateur peut parfois résoudre des problèmes techniques.

Contacter l'administrateur

Si vous ne trouvez pas de solution à votre problème dans cette page d'aide, n'hésitez pas à contacter l'administrateur qui se fera un plaisir de vous aider.
